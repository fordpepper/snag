Install

Copy the repo with git and build it. You need Go 1.21+, yt-dlp and ffmpeg.

# Arch. Debian/Ubuntu: sudo apt install golang ffmpeg pipx && pipx install yt-dlp
sudo pacman -S go yt-dlp ffmpeg

git clone https://github.com/fordpepper/snag
cd snag
make
sudo make install   # optional

snag

The clickable screen needs a unix terminal. On Windows pass the link as an argument, or run the Linux steps inside WSL.

Use

Run snag, paste one or more links, press Enter. Click a setting to change it, or use Tab and the arrow keys. Choices are remembered. Every file goes to your Downloads folder.

  • Resolution
    The highest available by default. Pick a cap to save space.
  • Audio
    Best quality, mp3 by default. Also m4a, opus and flac.
  • Playlist
    Turn on to take a whole playlist, channel or profile.
  • Cookies
    For private or age-gated posts such as Instagram stories. Uses the login from the browser you pick.

Notes

  • Watermarks are avoided by taking the original stream a site serves, not by editing the video.
  • Sites change often. If one stops working, update yt-dlp first.
  • Only download what you have the right to, and respect creators.
