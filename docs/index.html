snag

Download video and audio from YouTube, TikTok, Instagram, X, Reddit and about a thousand other sites. One small binary, clean files, no watermarks.

Command builder

Browsers can't fetch from these sites directly, so downloading happens locally with the CLI below. Paste a link to get the command.

snag <url>

Supported

VideoYouTube, TikTok, Instagram (posts, reels, stories, highlights), X, Reddit, Facebook, Twitch, Vimeo, Dailymotion, Bilibili
AudioSoundCloud, Bandcamp, Mixcloud, or any video with -a
MoreAnything yt-dlp supports

Install

You need Go 1.21+, yt-dlp and ffmpeg.

# dependencies (Debian/Ubuntu; Arch: pacman -S go yt-dlp ffmpeg)
sudo apt install golang ffmpeg pipx && pipx install yt-dlp

# build
git clone https://github.com/fordpepper/snag
cd snag
make
sudo make install   # optional, installs to /usr/local/bin
brew install go yt-dlp ffmpeg

git clone https://github.com/fordpepper/snag
cd snag
make
sudo make install   # optional
winget install GoLang.Go yt-dlp.yt-dlp Gyan.FFmpeg

git clone https://github.com/fordpepper/snag
cd snag
go build -o snag.exe .

Usage

snag https://youtu.be/dQw4w9WgXcQ
snag -a https://soundcloud.com/artist/track
snag -q 720 -o ~/Videos https://x.com/user/status/123
snag -p https://www.tiktok.com/@user
snag -b firefox https://www.instagram.com/stories/user/
-aaudio only, mp3
-q Nmax height in pixels
-o DIRoutput directory
-b NAMEread cookies from a browser, for private or age-gated posts
-pwhole playlist or profile
-vverbose output

Notes

Watermarks are avoided by fetching the original stream the site serves, not by editing video. Sites change often; if something breaks, update yt-dlp first (yt-dlp -U or pipx upgrade yt-dlp).

Only download what you have the right to. Respect creators and each site's terms.
