Install

Copy the repo with git and build it. You need Go 1.21+ and ffmpeg. snag fetches yt-dlp itself the first time it needs it.

# installs ffmpeg, yt-dlp and Go (pacman, apt, dnf, zypper), then builds snag
git clone https://github.com/fordpepper/snag
cd snag
sh install.sh

snag

The clickable screen needs a unix terminal. On Windows pass the link as an argument, or run the Linux steps inside WSL.

Use

Run snag, paste one or more links, press Enter. Click a setting to change it, or focus it with Tab and just type (720, mp3). Choices are remembered. Files go to your Downloads folder unless you type another path.

  • format
    mp4 for video, mp3 for audio only.
  • resolution / quality
    the highest available by default. pick a cap to save space, or a bitrate for mp3.
  • browser
    only browsers installed on your machine are listed. leave it on none unless a site asks you to sign in (age-gated posts, instagram stories, youtube bot checks).
  • path
    in the terminal screen, type a folder to change where files go. the default is your downloads folder.

In the browser

Run snag serve and open http://localhost:8787, or use the box at the top of this page. The page sends your links to snag on your own computer, which fetches the file and hands it to your browser. Nothing goes through anyone else's server. On Android this works in Termux too.

Notes

  • Watermarks are avoided by taking the original stream a site serves, not by editing the video.
  • Sites change often. If one stops working, update yt-dlp first.
  • Only download what you have the right to, and respect creators.
